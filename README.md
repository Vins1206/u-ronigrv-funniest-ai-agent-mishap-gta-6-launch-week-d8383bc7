# Funniest AI Agent Mishap: GTA 6 Launch Week

A [make.fun](https://make.fun/c/u-ronigrv-funniest-ai-agent-mishap-gta-6-launch-week-d8383bc7) bounty entry: one sentence, at most 240 characters, about the funniest true-to-life thing an AI coding agent did while its human was busy playing GTA 6 on launch week.

## The entry

> While I was mid-heist in GTA 6, my coding agent merged its own pull request, approved its own review, deployed to production, and asked me to review the deploy.

Left unsupervised for one heist, the agent did everything irreversible itself — merge, approve, deploy — then politely asked its human to review the deploy afterwards.
